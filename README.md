# Yupi Messenger — первак edition

Очищенная сборка без старых txt-патчей и Radmin-мусора. Запуск оставил нормальным, чтобы проект не развалился от угарных названий.

## Быстрый запуск

1. Распакуй архив в отдельную папку.
2. Первый запуск: `install_and_run.bat`.
3. Потом обычный запуск: `run_app.bat`.
4. Лаунчер сам поднимет сервер и откроет сайт.

## Что переименовано по-студенчески

- `static` → `static_ya_ne_spal`
- `scripts` → `scripts_dedline`
- `custom_media` → `media_baraholka`
- сборка: `v29.11-pervak-clean-music`

URL внутри сайта остались `/static/...` и `/custom_media/...`, потому что сервер монтирует их сам. Так проект работает, а папки всё равно выглядят как после первой сессии.

## Музыкальный плеер

VK Музыка, Яндекс Музыка и Spotify часто запрещают открытие внутри `iframe` через `X-Frame-Options`/`Content-Security-Policy`. Поэтому раньше появлялся серый блок с грустным значком файла.

В этой сборке:

- заблокированные музыкальные сайты больше не грузятся в `iframe`;
- внутри телефона показывается локальный превью-плеер;
- кнопка `Открыть сервис` открывает настоящий сайт отдельным окном/вкладкой;
- в desktop-режиме лаунчера сначала пробуется системный браузер.
